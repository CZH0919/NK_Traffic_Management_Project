# 报表导出与 AI 简报

报告将指定范围的统计、对比、历史风险、预测回测或采样流量保存为可再次打开的结果。进入“报告与简报”，选择类型和范围后生成；已有统计页面、风险／预测结果页及“我的查询”均提供报告入口。首次打开不进行提交校验；标题可留空自动命名。切换类型保留标题及相容日期，地点与已完成计算通过搜索选择，随后核对来源范围。细分条件按需展开。生成、导出和简报由后台分析进程处理，离开页面后任务继续运行。

## 1. 保存与复查

- 统计、对比和流量报告冻结生成时的指标、图表、完整汇总表、范围、质量说明及来源版本。风险与预测报告引用已完成且不可变的计算结果，另保存规则与参数副本。
- 报告同时展示报告生成时间、来源数据截至日期、修订水位；风险／预测另列原分析时间。来源最新日期不能当作实时路况或模型验证日期。
- 后续数据修订不会改写历史报告。重新生成创建新记录；个人查询保存的是条件，重新载入使用当时的数据。风险／预测查询须先有与条件对应的已完成计算。
- 报告、附件及简报只对所有者开放，并要求查询分析和报告权限。管理员身份不自动取得其他用户的私人报告。

## 2. CSV、Excel 与打印

事故、车辆、人员检索页可导出全部筛选结果；流量页可按地点、日期和每日时刻导出观测明细。报告可导出所有汇总表、全部风险对象、所有预测点、参数比较／独立回测及异常判断，不受页面分页影响。

| 形式 | 内容与容量处理 |
|---|---|
| CSV 数据包（ZIP） | UTF-8 BOM；每表每五十万数据行拆分文件，重复表头；另附 `00_说明.csv` |
| Excel（XLSX） | 流式写入；每表至多 1,048,575 数据行，超出另建工作表；第一张表为说明 |
| 报告打印／另存 PDF | A4 摘要、主要指标和图表、口径及来源；摘要明确只展示各表前十二行和主要字段，完整数据另附 CSV／Excel |
| 简报文本／PDF | 当前模型稿或用户编辑稿，附模型、生成时间及编辑版本；原始稿保留在页面，报告 Excel 同时保留模型稿与当前稿 |

点击“打印摘要／另存 PDF”后，在浏览器打印窗口选择保存为 PDF；建议 A4、启用背景图形，并检查预览。打印摘要与完整附件共同组成报告材料，摘要不替代全部明细。

空值保留空单元格，真实零保留数值零。CSV 中可能触发公式的文本加前导单引号，Excel 文本作为字符串写入，数据库原文不变。超过十五位有效数字的整数／小数在 Excel 中按文本保存；超过单元格容量的文本明确报错并提示改用 CSV，不悄悄截断。日期与时刻按字段注明采用纽约当地时间或 UTC。观测明细中的冲突／排除行可作证据导出，不能因此参加可靠流量统计。

说明表保留筛选条件、单位、来源快照、数据版本、数据截至日期和质量解释；风险／预测附件另保留规则参数和原分析时间。文件只在全部写入和行数核对成功后发布，失败不会提供半成品。

## 3. 模型配置

后端读取 `AI_CONFIG_FILE` 指向的 UTF-8 JSON 私有文件；示例不含真实密钥：

```json
{
  "schema_version": 1,
  "provider": "deepseek",
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-flash",
  "api_key": "填写私有密钥"
}
```

私有文件和实际 `.env` 排除在源代码提交材料之外。服务地址必须为 HTTPS，并在 `AI_ALLOWED_HOSTS` 内；默认仅允许 `api.deepseek.com`。请求不跟随重定向，密钥只放在后端认证头，不进入网页、报告或错误日志。接口依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/)及 [JSON 模式说明](https://api-docs.deepseek.com/guides/json_mode/)。

调用控制默认值：每用户最近二十四小时 `AI_DAILY_CALL_LIMIT=20` 次尝试，每简报 `AI_MAX_ATTEMPTS=3` 次；输出上限 `AI_MAX_OUTPUT_TOKENS=2200`、请求超时 `AI_REQUEST_TIMEOUT=60` 秒、温度 `AI_TEMPERATURE=0.2`。每用户同时处理一个简报，失败重试也计入次数。通过环境变量配置，修改后重启服务。

## 4. 生成、编辑与核查

1. 打开已完成报告。尚无简报时点击“生成 AI 简报”；已有稿件优先使用报告列表或首屏的“查看已有简报”。如需按当前配置生成或复用，展开“简报与附件”中的“简报生成选项”。查看不会发起模型调用。后端只提交已计算的范围、汇总事实、规则和质量限制，不上传人员／车辆逐行明细。
2. 模型组织事实解读、解释限制及核查建议。每段必须引用输入中的事实或限制编号，正文不得自行添加阿拉伯数字；系统校验引用后插入原始数值依据。排名摘录与完整分布明确区分。
3. 查看结果及依据，选择“编辑简报”，补充或修正文案并保存。编辑后保留原始模型 JSON、模型稿、当前编辑稿与逐次编辑记录；并发打开的旧版本不能覆盖新编辑。
4. 再次打开、下载文本、打印，或从报告导出包含简报的 Excel。同一报告、相同汇总、模型与提示版本下复用成功结果，保留生成时间和人工编辑；不同报告分别保存简报归属。

自动校验限制的是结构、引用及数字来源，不能证明全部文字判断正确。因果解释、建议适用性和人工编辑后的数字仍须对照报告核查。历史强度不代表未来概率；经验参考带不代表已经验证的置信概率；尚未发生的未来事故不能声称已验证。

配置缺失、超时、额度或限流、认证失败、无效结构及输出被截断均显示失败原因，不保存为成功简报。修正原因后可显式重试；模型或提示规则改变时保留旧失败记录并按当前规则重新生成。模型不可用时，普通查询、统计、历史报告及文件导出仍可使用。

## 5. 实现与验证边界

报告采用共享 Django 模板与本地 CSS／JavaScript；图表由保存结果生成内联 SVG。CSV／Excel 在后台流式写入受控附件目录；任务、简报和编辑记录存入 PostgreSQL。成功报告、导出元数据和分析子结果由数据库触发器保护。

真实导出覆盖百万级人员分卷、完整道路评价与预测回测；文件经程序重新打开及独立行数核对。浏览器打印结果经 PDF 渲染核对，简报完成真实接口生成及编辑回看。程序读取 XLSX 不等同于已验证所有 Excel 客户端版本；最终排版及内容由人工验收进一步确认。

新版报告使用业务名称和单位，详细计算规则可展开。简报只有实际截取较长列表时才说明摘要范围；原有报告与模型原文、编辑稿保持原样，表达更新通过新报告和新简报呈现。

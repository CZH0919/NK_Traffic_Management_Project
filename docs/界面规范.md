# 界面与交互规范

界面以中文为主，保留来源英文名及代码用于追溯。风格为正式的城市交通研究工作空间。默认浅色采用白色面板、浅冷灰工作区、深蓝文字和青绿主操作；可切换为深蓝灰分层背景、浅灰正文和柔和青绿强调的深色外观。使用本机中文无衬线字体，无外部字体或在线图像依赖。

## 1. 信息架构

全系统导航依业务职责组织为工作台、事故档案、道路地图、采样流量、统计对比、历史风险、预测回测、报告简报、数据来源、账户与权限、操作记录。只有存在真实可用流程的入口才显示；权限控制同时应用于后端与导航。当前已启用基础业务、质量维护、空间流量、统计对比、历史风险、预测、报告与运行维护入口。

面包屑位于顶栏，当前导航保持选中。页面标题说明当前任务，副文案解释数据或操作，不堆砌技术栈。主操作优先放在标题右侧；窄屏移至下一行。退出必须提交 POST 表单。

## 2. 设计令牌

| 类别 | 约定 |

| 主文字 / 辅助文字 | #17314f / #6a7f96；关键说明不能只靠低对比浅色表达 |

| 成功 / 失败 | #097c77 / #b5423e；同时提供文字，不能只靠颜色 |
| 风险等级 | 从浅到深的有序配色，危险强调用暖色；另显示级别、单位与规则，不把等级当预测概率 |
| 字体 | Microsoft YaHei、PingFang SC、Noto Sans CJK SC、system-ui |
| 字号 | 主标题 32；区块 20；正文/表单 14—16；辅助 12—13；窄屏标题 25 |
| 间距 | 基本 4/8/12/16/20/24/32；内容左右 28，窄屏 16 |
| 圆角 | 面板 10，按钮和输入 6，采用柔和低对比阴影，不叠加多层容器 |

组件由共享模板与公共样式维护，不为每页复制布局。面板用于一个连续任务，避免层层套框。数据表优先于无意义卡片。工作台的数字由已发布快照支持；无来源数据用破折号和文字说明，真实零值才显示 0。

## 3. 表格、筛选与状态

表头使用 th、单位进入字段名/标题，时间显示明确当地语义。长表服务端分页，排序必须稳定；组合条件采用统一序列化结构。筛选区包含可见 label、查询和重置。列表空状态解释没有符合条件的数据；数据未发布时区分“没有数据集”与“筛选无结果”。

表单错误紧靠字段并有 role=alert；提交成功有 aria-live 通知。数据库不可用返回正式 503，不输出异常堆栈。无权限显示 403 与返回入口；错误 URL 显示 404。后续异步导入/分析需显示排队、执行、成功、部分失败及错误原因；不显示空转动画冒充实际进度。

后续图表须包括标题、统计单位、图例、时间范围、截止日期与质量说明；地图在底图失效时仍显示受控业务图层。点加载按视野聚合，图表/地图与列表共享筛选。图表容器明确高度，resize 时重新布局；打印时保持坐标轴/图例完整。

## 4. 响应式与可访问性

桌面使用固定侧栏与可滚动内容；宽度不超过 900 时侧栏折叠，可用菜单按钮、遮罩和 Escape 收起；小于 650 时概览变为两列，其余主要面板单列。长表在自身容器内横向滚动，不能撑宽整个页面。登录页窄屏保留品牌和表单，避免文字插画占据主要操作区域。

提供跳转至内容链接、清晰键盘焦点、aria-current、按钮展开状态、表单自动填充语义和可见标签。菜单、按钮与列表状态使用 150—180 ms 的克制过渡，并遵守 prefers-reduced-motion。字体依赖本地回退，因此不同系统字形不要求像素相同，但不能溢出或影响可读性。

## 6. 视觉增强与业务组件

在既有白色导航／内容与浅冷灰工作区上增补统一样式：深蓝正文、青绿主操作、轻微冷色渐变、细边框和柔和阴影。登录区及标题区域的本地 SVG 交通线稿仅为装饰，aria-hidden，不能当作实际道路或分析结果。保留系统中文字体与原 SVG 图标风格，不依赖在线字体、图像或 emoji。

列表采用独立筛选区、结果表与行操作；详情分为事实属性、来源、关联与变更记录；表单共用字段、帮助与错误组件。来源／质量／任务状态以文字配合语义色显示。窄屏按单列组织，数据表在可聚焦的容器内横向滚动。原始证据只读，修改页面展示版本、理由和提交结果。

## 7. 当前业务导航与状态

导航分为“查询与地图、分析与报告、数据与来源、系统管理”，仅显示已实现并有权限的入口。事故／车辆／人员共用分页、组合筛选、详情、编辑和有效状态组件；侧栏保持统一 SVG 图标。

质量面板、任务详情分别表达处理状态和统计资格；来源缺失不显示为零，失败页面说明结果及返回入口。加载中的导入任务每约 3 秒更新状态，服务离线时显示排队原因；不播放无实际进度的循环动画。管理员使用账户维护及审计详情，分析用户的界面不显示维护动作。

键盘焦点采用明确的青绿 3px 外轮廓；移动导航提供遮罩、关闭按钮、焦点约束和 Escape 退出。表格允许局部横向滚动，整页不横向溢出。数字、状态和标题的视觉层级在桌面、笔记本与窄屏一致。

## 8. 统计与历史风险组件

统计使用青绿时序折线、来源类别横条及可下钻指标卡；对比曲线用青绿实线和赭色虚线区分 A/B。所有图形配服务端数值表，空缺不连成真实零值；类别图前 20 类有明确说明。图表遵守减少动效偏好。

历史风险用蓝、赭、橙、红与灰色等级标签，同时提供文字、分值与规则。地图目标使用固定大小符号，不叠加数量大小暗示第二种风险含义；视野截取范围、最多 500 个、代表点位及历史版本均明示。详情贡献条同时显示精确数值，支撑不足不显示伪造分值。

异步风险任务约每 2 秒读取实际状态，完成后转为结果页；服务离线或失败提供原因和重新计算入口。主要筛选条件进入 URL；保存表达、地图、表格和明细保持一致。

## 9. 深浅色外观

登录页和页面顶栏提供同一个切换按钮，显示当前“浅色／深色”状态，使用内联 SVG 和 `aria-pressed` 表达选择，支持键盘操作。默认浅色，偏好保存在当前浏览器同源存储中；刷新、页面跳转和退出登录后保持选择。浏览器不允许保存时，当前页仍可切换。选择不写入业务数据库，不影响角色、查询、算法和历史结果。

深色使用工作区 `#10202d`、面板 `#192e3d`、次级面板 `#213a4a`、正文 `#e0eaf0`、辅助文字 `#adbfcc` 和强调 `#61c9c1`。成功、警告、错误及风险分级继续用文字配合语义色。表单、禁用态、焦点、表格、弹窗、地图控件、图表轴线／图例／提示及报告阅读面板使用协调色阶。

图表仅更新颜色样式，保留时间轴、图例选择、值和下钻事件；详细底图、研究范围与业务图层按类型更换颜色，保留视野与选择，不反转整张地图颜色。报告中的 SVG 仅改变屏幕样式，不改写已保存报告内容。打印始终使用浅色，并展开打印所需来源信息；关闭打印恢复浏览器内的主题选择。

主题资源位于 `static/css/theme.css`、`static/js/theme.js`，公共按钮为 `templates/components/theme_toggle.html`。新页面应复用公共模板与语义样式；独立登录和服务错误页也提供切换入口。


## 10. 任务帮助与交互一致性

使用指南由简短入口页与独立主题页组成，搜索覆盖操作、字段、结果和常见问题。上下文帮助直达相应主题；辅助帮助在新窗口打开。主题目录在窄屏收起，常用正文连续阅读，方法和少见问题按需展开；打印仅包含当前主题。

表单区分必填与可选，切换对象时同步调整约束。第一次进入不显示提交错误；修改筛选后标记条件尚未应用，提交后结果采用实际条件。重复提交受到抑制，浏览器返回后恢复操作。维护页取消不保存；仅有未保存编辑内容时提示离开。

道路、路口、地点、事故、车辆和已完成计算使用共用选择器，支持搜索、分页、选择、清除、Escape、无结果及失败重试。车辆候选随事故关联变化；内部编号保留为高级入口。

维度决定统计单位：车辆／人员维度固定为明细条数，因素为涉及事故数，其余维度可选事故或伤亡指标。控件、URL、保存查询、下钻和报告使用同一生效值。

正常时间和来源细节按需展开；会影响解读的缺失、异常、采样覆盖及不可比原因直接说明。大数分组，日均特征默认两位小数且可查看精确值。完整率结合实际缺失数表达，不把接近 100% 显示为全部完整。

质量核查分开显示来源原值、当前业务值与历史检测明细；缺少历史依据时明确标识。当前坐标核对注明边界版本与时间，不更新业务或冒充原检测证据。

# 统计与历史风险评价

综合统计用于描述已登记的事故与关联记录；历史风险用于在明确参照群体内识别值得关注的对象。二者均使用已发布、有效、官方来源数据，采用纽约当地日期和来源时钟小时。历史强度不等于未来事故概率，也不等于单位出行事故率。

## 1. 统计与下钻

从“统计与对比”选择日期范围、行政区、统计维度及事故指标。高级条件包括网络、道路或路口、年份、月份、星期、小时、严重程度和地图矩形范围。道路和路口不能同时选择；空间过滤使用当前有效且输入修订未过期的关联。位置缺失记录仍进入不含空间条件的全市时间统计。

| 内容 | 单位与计算 |
|---|---|
| 登记事故 | 每个事故事件一次，不按车辆或人员展开 |
| 已报告伤亡 | 对事故级受伤、死亡列分别求和，同时列出缺失；全缺失为未知，不以人员明细替代 |
| 严重程度 | 有死亡；死亡为零且有受伤；报告伤亡均为零；其余不确定，四组互斥 |
| 车辆类型、人员类型、人员伤害 | 对相应明细表分别计数，保留来源类别原文；空文本单列为未提供，不套用档案检索的统一类别映射 |
| 事故因素 | 同一因素按涉及事故去重，来源槽位重复不重复计数；不同因素可重叠，不能相加当作事故总数，更不能解释为因果认定 |
| 年、月、日期、星期、小时、行政区 | 按事故当地日期／时钟分组；行政区未知、时间缺失单列 |

指标卡、图形和统计表中的数值均有支撑记录入口，明细每页 30 条并可进入原有档案。类别图展示前 20 类，分页表包含全部类别。统计地图使用相同筛选，平移和缩放仅改变显示视野；点击“按当前视野统计”才将矩形范围同步到图表、明细及保存条件。有坐标记录的数量聚合不是风险分数。

统计地图首次展开后才载入本地详细底图，收起后停止业务刷新。再次展开复用地图；刷新／返回保留显示状态，显示状态不会进入保存查询或报告的计算条件。已应用的视野以紫色短虚线标识，可“解除视野范围”。最多显示 1,000 个点或聚合单元，达到上限时分别报告准确事故总数和已显示对象数；聚合数字使用真实事故数量，点击和“查看地图数据”都可查阅准确值。切换车辆／人员维度时，地图依然统计事故，不把明细条数当作事故点数。

道路、统计与风险地图共用离线参考底图及含水域的纽约市研究范围；范围开关不改变分析条件。详细地图的滚轮缩放需配合 Ctrl，触屏用双指移动，普通页面滚动不会被地图拦截。地图加载失败时可点击“刷新地图”重试，原统计筛选和已保存的风险结果保持不变。

覆盖依据是已经全量核验、数量对账一致的来源快照；局部上传文件不证明整个日期区间完整。完整覆盖内没有登记行的时段显示 0，覆盖外图形留空。页面登记数表示当前可用记录，不代表掌握现实中的全部事故。车辆、人员与事故分别核验来源覆盖。

## 2. 区域与期间对比

A、B 可选择相同期间的不同区域，也可选择同一区域的不同期间；其他细分条件共同作用于两组。道路／路口条件只在两组行政区相同时适用。

- 绝对变化为 **B−A**；相对变化为 **100×(B−A)/A**。
- 总量相对变化要求两组来源覆盖完整、天数一致、基数非零；伤亡指标还要求相关字段没有缺失。条件不满足时解释原因，不强行输出百分比。
- 来源覆盖完整但天数不同，可比较日均登记量。例如全年跨闰年时使用 365 与 366 天各自的分母。日均仍不控制节假日、天气、报告政策或交通暴露差异。
- 两条曲线按各自第几日对齐，提示实际日期；较短期间结尾不补零。图表、表格、A/B 汇总各自保留正确的下钻范围。
- 同期行政区未知事故单独提示，不按五区比例分摊。

## 3. 默认历史强度规则

评价对象为全市、行政区、道路代表要素、已认定的真实路口。道路／路口分子只使用所选网络的有效确定关联，待核查、过期关联、无位置和候选范围外记录不被强行分配。道路同名并不合并为一条道路，内部目标与来源路段身份可回查。

设窗口长度为 D 天，事故数为 N，已报告受伤为 I，已报告死亡为 K；末尾 R=min(90,D) 天内事故数为 Nr。默认 v1 的三个特征如下。

| 特征 | 原值 | 权重 |
|---|---|---|
| 事故频次 | N / D | 50% |
| 已报告伤亡负担 | (I + 5K) / D | 35% |
| 近期事故强度 | Nr / R | 15% |

死亡系数 5 是项目描述性规则，不是官方损失定价。少量伤亡缺失时只使用已报告合计，不向来源补零，并提示负担可能低估。

三项分别计算经验中秩百分位：`100 × (小于当前特征的参照数 + 0.5 × 等于当前特征的参照数) / 参照总数`。真实零特征记 0。分数为三项百分位乘权重之和，保留三位小数。

道路／路口使用同层级、同期间且满足条件的目标作为参照；行政区使用五区共同参照，筛选某区只限制结果显示。全市只有一个目标，因此采用截至窗口末日、已经完整覆盖的全市月份作为参照，至少 6 个月；月份按各自天数归一，其中近期项参考月日均频次，不使用期末之后的月份。计算记录保存参照类型、规模和特征范围，页面显示类型、规模及各项贡献。不同参照群体、层级、时间窗或规则的分数不能直接相减。

| 默认分级 | 范围 |
|---|---|
| 相对较低 | 分数 < 40 |
| 中等 | 40 ≤ 分数 < 60 |
| 较高 | 60 ≤ 分数 < 80 |
| 很高 | 分数 ≥ 80 |
| 不分级 | 支撑、字段完整率、来源覆盖或参照不足 |

默认要求至少 5 起支撑事故、伤亡总数字段完整率至少 95%、来源日期完整覆盖。低于门槛仍保存数值和原因，分数为空。道路／路口只列出有确定关联事故的对象，没有出现在结果里不表示安全。分值没有按人口、道路长度或出行量消除规模差异。

## 4. 计算、重算与解释

1. 在“历史风险评价”选择日期、区域、网络、层级和规则，点击“计算历史风险”。任务在本机数据库排队，由分析进程执行，页面显示等待、执行、完成或失败状态。每位用户同时只允许一个待处理任务。
2. 完成后查看分级、并列名次与热点；名称／等级筛选同时作用于列表和地图。地图按当前视野显示分数排序前 500 个目标，其余通过放大、筛选及分页查询。点位为该次已保存结果的代表位置，全市单一目标直接以汇总展示。颜色与等级文字同时呈现；点击标记或展开“查看地图数据”，查看精确分数、支撑量和评分依据。无评分与零分明确区分。缩放、研究范围开关和主题不触发重算；旧版本提示按当前数据状态核验，历史点位与分数仍保留。
3. 详情显示事故和伤亡数、近期窗口、特征原值、百分位、权重、贡献、完整率及规则。可查看最近 12 起支撑事故，并进入同口径全部记录或综合统计。
4. “按当前数据重新计算”建立新的计算记录，保留旧结果及其规则。分析员可计算，管理员／维护人员可创建新规则；已有规则、分析目标、完成结果由数据库保护，不能覆盖或删除。

规则表单可调整权重、死亡系数、近期窗口、最少支撑和完整率门槛；权重总和须为 100，支撑门槛不低于 5、完整率不低于 95%，必须说明依据。分级阈值和标准化方法固定在版本参数中，更换算法需要受控代码及新规则版本。

## 5. 流量归一化与数据版本

道路评分详情单独列出有关联的采样地点及与评价窗重叠的观测范围。用户可核查流量归一化条件，复用[道路地图与流量分析](道路地图与流量分析.md)中的双向、历史适用范围、目标修订、共同有效时隙、可靠分母和事故归属条件。条件不足则解释原因，不将全年事故除以零星采样日，不把该指标加入历史强度分。

普通统计在一致数据库快照中计算，缓存最长 15 分钟。缓存以规范化条件、引擎版本及“发布快照状态／范围＋业务修订水位”匹配；修正或发布后旧缓存不会命中，下一次请求重算。风险在独立事务中计算并持共享维护锁，完整提交所有目标与结果；错误整批回滚派生结果，不修改原始业务事实。

历史风险保存当时数据版本、规则、条件、计数、特征和目标点位。数据变化后结果显示历史提示，并停止把当前事故明细当作旧结果的支撑；重算才恢复当前明细入口。这里保留的是聚合计算证据，不是每个历史时点的完整业务库快照。

个人查询只对本人可见。统计与对比在更新结果后使用“保存这组查询条件”；风险设置页直接使用“保存查询条件”，服务端验证当前表单且不启动计算。统计与对比载入后按保存条件查询当前数据，风险查询恢复网络、规则和时间范围，待用户再次点击计算。查询表达与计算结果分别保存。

Bootstrap 使用 MIT 许可，Leaflet 使用 BSD-2-Clause 许可；完整许可分别保留在对应 LICENSE 文件。ECharts 的 LICENSE、NOTICE 一同保留，具体组件声明以原文件为准。分发本地资源时须保留这些文件，不移除文件头版权说明。

静态发行文件通过官方项目或 npm 固定版本取得，资源来源和完整性信息保存在 `config/map_resources.json`。当前页面不依赖在线 CDN、字体或瓦片服务。地图使用本地裁剪的 Protomaps 2026-10-27 区域 PMTiles，底图源于 OpenStreetMap 和 Natural Earth；OpenStreetMap 数据遵循 [ODbL 1.0](https://www.openstreetmap.org/copyright)，Natural Earth 为公共领域。地图保留 OpenStreetMap／Protomaps 署名，底图作为地理背景，不作为本项目的交通事实来源。

分发离线区域数据库时须连同来源、版本、ODbL 许可说明与适用义务保留；该文件不包含在普通源码 Git 备份内，可用固定资源清单和安装脚本重新提取。没有抓取 OSM 标准公共瓦片服务。准备资源的 PMTiles CLI 是一次性部署工具，不是运行依赖。

交通来源归 NYPD、NYC DOT、NYC DCP 等发布机构；引用时保留机构、数据集标识、快照时间和源版本。本系统不是发布机构官方产品，不保证源记录涵盖现实中全部事故。具体数据使用条款在正式快照登记时记录。

## 本地空间展示数据

`static/data/borough_land.geojson` 由已归档 NYC 行政陆域数据生成，用于离线展示；保留五区代码、名称和 WGS84 几何，采用保持拓扑的显示简化。距离计算与业务查询使用数据库中的来源几何，不使用显示简化后的边界代替测量。页面地图注明 NYC DCP / NYC Open Data 来源。

`static/data/nyc_research_boundary.geojson` 基于同版 NYC DCP [含水域行政区边界 wh2p-dxnf](https://data.cityofnewyork.us/resource/wh2p-dxnf.json) 派生。五区合并形成全市轮廓，保留内部区界；区名位置参照 [去水域边界 gthc-hcne](https://data.cityofnewyork.us/resource/gthc-hcne.json)。文件内保存来源、26b 版本、坐标系和 5 米显示简化容差。该层用于识别研究范围，不改变分析资格。源码包含可重复生成脚本，原始快照按数据归档方式另行保管。

Bootstrap 使用 MIT 许可，Leaflet 使用 BSD-2-Clause 许可；完整许可分别保留在对应 LICENSE 文件。ECharts 的 LICENSE、NOTICE 一同保留，具体组件声明以原文件为准。分发本地资源时须保留这些文件，不移除文件头版权说明。

静态发行文件通过官方文档所列发行/CDN渠道取得。当前页面不依赖在线 CDN、字体或底图。地图底图服务如果后续选用，另行登记署名、条款与离线行为。

交通来源归 NYPD、NYC DOT、NYC DCP 等发布机构；引用时保留机构、数据集标识、快照时间和源版本。本系统不是发布机构官方产品，不保证源记录涵盖现实中全部事故。具体数据使用条款在正式快照登记时记录。

## 本地空间展示数据

`static/data/borough_land.geojson` 由已归档 NYC 行政陆域数据生成，用于离线展示；保留五区代码、名称和 WGS84 几何，采用保持拓扑的显示简化。距离计算与业务查询使用数据库中的来源几何，不使用显示简化后的边界代替测量。页面地图注明 NYC DCP / NYC Open Data 来源。

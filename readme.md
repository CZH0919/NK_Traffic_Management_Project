# 城市交通研究

基于纽约市多源开放数据的城市道路交通事故风险分析与交通流量管理数据库应用系统，面向本机浏览器使用。

当前提供事故、车辆与人员的组合检索、分页详情、关联追溯、授权修订、批量失效和恢复；同时提供数据质量核查、文件校验与后台导入、类别和来源维护、个人查询保存、账户管理与操作审计。登录、退出、密码修改及三类角色权限均在服务端校验。另提供本地道路地图、道路／路口档案、带证据的空间关联核查、采样流量分析，以及多维综合统计、区域和期间对比、全市／行政区／道路／路口的可解释历史风险评价与热点展示。周期预测提供周／月历史序列、基线和轻量方法比较、时序回测、经验误差参考带及历史异常回查。

首次五年完整快照的业务源记录为 3,598,632 条，另有全市道路、节点和边界。2,871 条非标准流量时间记录保留在暂存隔离层，未强制写成 15 分钟观测。后续文件副本按来源主键去重；原始证据数量可以大于业务记录数量。完整快照数量与限制见[正式数据快照核对](docs/正式数据快照核对.md)，当前交互使用说明见[业务操作与维护](docs/业务操作与维护.md)。

全系统数据与分析设计见 [详细设计](docs/详细设计.md)、[数据字典](docs/数据字典.md)和[设计图](docs/diagrams/图示说明.md)。

系统启动后，可从登录页或页面顶部进入“使用指南”（`/help/`），按任务查阅查询、地图、分析、报告与维护操作。“快速使用”介绍基本流程；登录页及页首可一键切换浅色／深色外观，浏览器记住选择，报告打印保持浅色。

## 运行条件

- Git 与 Git LFS（获取正式数据和离线地图）。
- Python 3.11；Django 5.2。
- PostgreSQL 17，项目数据库已启用 PostGIS 3.6。
- 现代浏览器；核心样式和脚本随项目提供。道路、统计与风险统一使用详细地图，浏览器需支持 WebGL 并启用图形加速。
- 日常应用账户拥有项目库内建表及读写权限，不需要超级用户、CREATEDB 或 CREATEROLE 权限。

## 获取源码与数据

安装 Git LFS 后克隆仓库。`main` 为最新可测试版本；固定官方快照和离线地图由 Git LFS 管理，数据清单与说明随普通 Git 保存。

```powershell
git clone https://github.com/CZH0919/NK_Traffic_Management_Project.git
cd NK_Traffic_Management_Project
git lfs install --local
git lfs pull
git lfs fsck
```

已有工作区无需重新克隆。确认本地改动已保存后，使用 `git pull --ff-only` 与 `git lfs pull` 更新。数据总量约 681 MiB；完整范围及指针文件识别见 [数据说明](data/README.md)，分支、目录职责和迭代规范见 [版本控制与目录规范](docs/版本控制与目录规范.md)。Git 更新不会自动导入数据库或修改已有账户。

## 配置与初始化

在已有 Python 环境中安装固定依赖：

```powershell
python -m pip install -r requirements-lock.txt
python -m pip check
```

复制 `.env.example` 为 `.env`，配置本机数据库连接和随机 `DJANGO_SECRET_KEY`。实际配置与任何密码均不应进入提交包。密码可以由环境变量提供，也可以使用 `DB_PASSWORD_FILE` 指向受保护的 UTF-8 文件；配置只由后端读取。

数据库管理员先建立项目数据库并启用 PostGIS，再使用普通应用账户执行迁移：

```powershell
python manage.py migrate
python manage.py bootstrap_accounts --credentials-file "<私有账户凭据输出文件>"
```

初始化命令创建管理员、数据维护人员和分析用户三个独立账户，生成随机密码并仅保存到指定私有文件。它不会覆盖既有文件或重置已存在账户。首次使用后可在“账户与权限”中修改密码。

## 启动与停止

在项目根目录运行：

```powershell
python scripts/run_local.py --port 8000
```

启动器同时运行网页服务、文件处理进程和统计分析进程（风险、预测、报告、导出与 AI 简报共用）。使用项目已有 `Traffic_Venv` 时，也可直接执行 `& '.\scripts\start_local.ps1'`。浏览器访问 [本地工作空间](http://127.0.0.1:8000/)，停止时在另一终端执行 `python scripts/run_local.py --stop --port 8000`，使用项目环境也可执行 `& '.\scripts\stop_local.ps1'`。普通交互终端也可以尝试 Ctrl+C；显式停止命令会同时收回网页与两个工作进程。

若需要分别运行，在三个终端分别执行 `python manage.py runserver 127.0.0.1:8000 --insecure --noreload`、`python manage.py run_import_worker` 和 `python manage.py run_analysis_worker`。任务页面会显示处理服务是否在线；仅启动网页时，排队任务等待相应处理服务运行。`--insecure` 为关闭 DEBUG 的本地开发服务器提供静态资源，服务仅绑定本机。数据库可能被其他项目共用，应独立管理其启停。

## 测试

管理员预建独立的 `test_nk_traffic`，所有者为应用账户，并在该库启用 PostGIS。`DB_TEST_NAME` 必须与业务库不同且以 `test_` 开头。

```powershell
python manage.py test tests --keepdb
python -m pytest --reuse-db
```

两条命令是可替换的测试入口。测试验证实际 PostgreSQL/PostGIS、关系与检查约束、角色权限、认证、事务、不可变证据和纽约夏令时规则；不会把业务库用作测试库。无 `--keepdb` 的 Django 测试被项目保护逻辑拒绝。

## 数据与使用边界

来源为 NYC Open Data 的事故、车辆、人员、采样流量以及 NYC DCP 道路网络。已获取纽约五区 2021—2025 年全部已发布事故、车辆、人员及采样流量快照，并采用 LION 26b 全市道路／节点和同版行政区边界。采集、导入、断点恢复、重复识别及发布命令见[数据导入与质量规则](docs/数据导入与质量规则.md)。来源登记、原始记录、业务记录和统计资格分别管理。

地图与流量使用方法见[道路地图与流量分析](docs/道路地图与流量分析.md)，统计、对比、评分规则和操作见[统计与历史风险评价](docs/统计与历史风险评价.md)。历史强度分不是未来事故概率，流量归一化指标需要独立通过暴露量资格核查。预测设置、回测及不确定性见[统计预测与回测](docs/统计预测与回测.md)。报告支持保存上述分析结果、完整 CSV／Excel 导出、A4 打印和浏览器另存 PDF；AI 简报仅接收确定汇总，支持生成、编辑、回看及导出。配置和操作见[报表导出与 AI 简报](docs/报表导出与AI简报.md)。业务维护和质量核查不会自动解除观测的统计限制。

道路地图、统计内嵌地图和历史风险地图共用协调的深浅色离线底图与纽约市含水域研究范围；道路地图还提供名称定位、附近范围和分级业务图层。统计视野只有主动应用后才改变分析范围，风险地图保留历史评分与代表位置。参考底图位于 `data/basemaps/nyc-20261027.pmtiles`，只用于地理背景；业务查询仍读取 PostgreSQL/PostGIS 中已发布的事故与路网。离线包通过 Git LFS 管理，新设备可拉取固定版本；重新提取方法见[地图说明](docs/道路地图与流量分析.md)。

事故时间采用纽约当地时间；模糊小时不会被任意解释为唯一 UTC。缺失、冲突、未匹配和采样不完整必须保留为明确状态。人员实体只描述统计属性，不采集姓名、证件及联系方式。

第三方资源及许可证见 [资源说明](docs/第三方资源说明.md)。

## 代码与数据版本管理

仓库包含正式应用、迁移、前端资源、回归测试、复用工具、文档，以及经核查的官方数据快照与离线底图。原始大文件使用 Git LFS，不直接写入普通 Git 对象。

本地数据库、账户、用户上传／导出、运行环境、私有配置、内部交接及开发证据单独保管。克隆代码和正式来源文件不会恢复已有业务修订、账户与历史分析成果；完整运行状态应通过受控数据库与文件维护包恢复，并补齐本机配置。只下载包含 LFS 指针的源码压缩包不能代替完整数据获取。

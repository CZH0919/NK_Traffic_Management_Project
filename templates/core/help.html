快速使用

登录页和页面右上角的“浅色／深色”按钮可一键切换外观，选择在当前浏览器内保存。切换不改变筛选或数据，报告打印仍使用浅色。不同浏览器或访问地址的选择分别保存。

  1. 登录后在工作台确认数据覆盖时间，再从“查询与地图”进入事故档案。
  2. 选起止日期和行政区，点击“查询”；点击“查看详情”，沿车辆与人员链接查看关联记录。
  3. 进入“统计与对比”，使用相同日期和区域查看数量分布。点击图表或表格数值可以查看支撑记录。
  4. 需要留存结果时生成报告；下次复用筛选时保存查询条件。

完成后应能找到记录、说明统计范围，并知道数字来自哪些资料。时间均按纽约当地时间展示。

账户与权限

分析员查询和分析数据、管理自己的查询与报告；维护员还可维护业务记录、核查质量问题和导入文件；管理员还可管理账户、规则及运行维护。具体可用操作以“账户与权限”页为准。

保存的查询、报告、导出和 AI 简报仅本人可访问。已完成风险与预测计算供有分析权限的账户查阅。看不到维护按钮时可继续查询，请联系管理员核对角色。

查询事故、车辆与人员

  1. 选择档案类型，填日期、行政区、道路关键字或来源记录编号。
  2. 需要查询演示记录、失效记录、人员伤情或特定关联对象时，展开“更多筛选”。页面始终标明来源与状态条件。
  3. 点击“查询”后查看结果；详情中的内部编号供系统关联，来源编号用来核对原始发布记录，两者不能互换。
  4. 沿“所属事故”、车辆、人员或“在档案中查看全部”继续查阅。使用“返回列表”保留进入详情前的筛选、排序和页码。

没有车辆或人员明细不表示人数为零；“未知”表示来源未提供。来源街道名称保留原文。维护记录必须填写依据；取消编辑不会保存修改。

道路、路口与地图

  1. 打开道路地图，选择行政区、事故日期后“应用筛选”。平移、缩放会更新视野内事故；“回到全市”保留筛选，“重置”清除筛选与选中对象。
  2. 底图随缩放呈现街名、建筑、绿地和公共地标，深浅色跟随页面外观。业务道路、路口、采样地点分级显示。事故数量符号可点击放大；悬停查看准确数量，k 表示千，数量不等于风险评分。
  3. 用“按名称定位”查找道路、路口或采样地点，核对来源编号、端点或长度后选择；同名路段是独立对象。也可点击业务图层中的对象查看档案或附近事故。
  4. “路网版本与附近范围”可设置路网及半径。阴影标出附近范围，查询还同时受日期、行政区与视野限制；附近不代表已关联。清除选中对象即可恢复视野查询。
  5. 关闭事故图层只隐藏符号，不清空事故列表或改变总数。翻页只更新列表，链接可保留当前条件与页码。缺少坐标的事故仍可从事故档案查询。

参考底图与 LION 业务路网来自不同来源／版本，底图不参与交通统计。地图资源已在本地安装；如详细地图不可用，点击“使用基础地图”继续查询。更换路网版本后，道路或路口需要重新选择。

查看交通流量

  1. 按街道、行政区或方向选择采样地点，核对起止街道和来源采样请求。
  2. 在该地点实际采样期间内选日期与统计粒度，查看每日、每小时或每 15 分钟观测。
  3. 需要比较时按名称选择比较地点，填写比较期间起日；比较窗口长度与当前窗口相同。
  4. 阅读有效时段、缺失时段和覆盖提示，再比较同时间位置的有效观测。

NB / SB / EB / WB 分别为北、南、东、西向。无采样、冲突或排除不当作零。这里是定点定时采样，不能据此推断全市实时交通或完整道路通行量。

  1. 范围需要道路或路口时按名称选择，并核对对象信息。
  2. 提交计算后可离开页面，稍后从“最近计算记录”查看进度及结果。
  3. “样本不足”或“不提供”是分析结论的一部分；不要把缺失补零，或改范围只为得到某个分数。
  4. 需要复用设置时直接填查询名称并“保存查询条件”，保存的是表单中当前条件，不执行计算。

统计默认使用官方、有效、已发布记录。旧计算保留原版本；出现数据变化提示时重算会建立新记录，不覆盖历史结果。

保存查询、报告与 AI 简报

  1. 保存查询条件：用于重复查询，载入时按当前数据重新计算；在“我的查询”中改名、归档或恢复。
  2. 生成报告：在分析结果页点击生成报告，核对已选来源与标题并提交。报告冻结当时的结果、规则和数据版本。
  3. 阅读或导出：报告页可跳转到摘要、完整数据、简报与附件。打印摘要可另存 PDF，完整数据通过 CSV 数据包或 Excel 下载。
  4. 生成或查看简报：已有简报时点击“查看已有简报”，不需要再次生成。首次生成将报告汇总及必要限制提交给已配置模型；普通报告和导出可独立使用。
  5. 编辑简报：核查引用和数字后保存编辑版本；模型原文保留，下载使用当前编辑版本。

简报为模型解释或用户编辑，不能替代报告统计及资料边界。同一输入可能复用已有简报并保留原生成时间。生成失败时查看原因后重试；不要反复提交等待中的任务。

导入与数据核查

维护操作需要对应权限；分析员可查阅质量说明和原始证据。

  1. 维护员选择官方来源后查看必需字段，上传原始 CSV、JSON 或 JSONL，可使用 gzip 压缩。
  2. 文件先排队校验。可离开页面，从导入任务返回查看；校验通过后仍需核对范围并确认导入。
  3. 导入完成后核对新增、重复、隔离与失败去向。校验行数仅代表该文件，不自动代表全量覆盖。
  4. 进入数据质量查看中文问题类型、关联业务记录和原始证据。需要修正业务事实时按依据维护；核查结论本身不解除统计限制。

演示和人工记录从档案维护入口建立，默认统计不包含演示记录。失效操作保留原始证据与关联；失效事故会影响其有效车辆与人员，恢复不会自动恢复全部明细，确认前须核对范围。

常见问题与术语

查询没有结果
先检查日期覆盖，再检查行政区、来源、状态和已展开的细分条件；必要时“重置”。没有匹配记录不等于现实中没有事故。
来源编号与内部编号有什么区别
来源编号由发布方提供，内部编号用于本系统关联。搜索框会明确名称，按名称选择对象可以避免混用。
数据版本、规则版本与网络版本
分别标明计算采用的数据状态、方法定义和道路几何版本。历史报告仍保留生成时的这些信息。
零、未知、不适用和样本不足
零是已报告零值；未知表示缺失；不适用表示方法条件不成立；样本不足表示证据不足以给出可靠结果。
任务很久未完成
保留原任务链接，检查服务在线提示；刷新状态或稍后返回。失败时先阅读原因，再按页面提供的入口重试。
AI 简报不能生成
普通报告仍可使用。确认报告已完成并查看错误提示；模型配置与服务连接由管理员核查，密钥不在页面填写或展示。
没有权限或登录过期
重新登录原账户；私人报告不能通过另一账户访问，角色问题请由管理员核对。
看到“隔离数据副本”
表示当前修改与新增文件和主业务数据分开保存。操作前确认正在使用的工作空间。
